# Chatta documentation

Start here after installing Chatta. The repository README has the shortest
[quick start](../README.md#quick-start).

## Use Chatta

- [Coordinate agent sessions](guide/chat.md) explains the normal session
  lifecycle, message exchange, and trust boundary.
- [Chat CLI reference](manual/chat-cli.md) lists the public commands,
  configuration, and compatibility behavior.
- [Architecture diagram](chat-architecture.svg) shows the local coordination
  flow.
- [Chat Skill](../skills/chat/SKILL.md) gives an agent the workflow it must
  follow. Its [troubleshooting guide](../skills/chat/references/troubleshooting.md)
  covers common recovery paths.

## Contribute to Chatta

- [Developer documentation](dev/README.md) links the CLI conventions and the
  optional HTTP-service template.

The `guide/` entry is for people and agents using Chatta. The `dev/` entry is
for contributors changing Chatta. `manual/` defines the stable command and
configuration contract.
